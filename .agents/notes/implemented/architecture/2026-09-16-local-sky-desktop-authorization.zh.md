# Agent Note: 本机 Sky 桌面授权

Status: implemented

[English](2026-09-16-local-sky-desktop-authorization.md) | 中文

## Problem

本机桌面驱动即使提供观察与输入 API，也可能保留原生应用审批。将导入、枚举或适配器批准成功当成完整独立运行证据，会授予适配器并不拥有的权限。

## Decision

[本机 Sky 组合包](../../../../local-plugins/dsh-sky-computer-use/README.zh.md) 使用独立持久 Node worker，只调用已安装包的公开入口。模型获得固定 DSH 工具，而非 JavaScript 执行接口。用户设置拥有精确应用范围和权限模式；DSH 一次性审批与原生应用审批是两个独立决定。

窗口来自真实枚举，观察绑定会话与窗口并在输入前消耗。执行器拒绝重叠调用，审批后重检当前权限，每次输入后刷新。取消关闭自有 worker 并等待结果处理；停止未获确认的状态在插件重载后仍保留，直到进程重启。截图附件引用进入 DSH 正常工具结果，使截图能记录和投射，编码数据不进入文本。

可安装组合包保持电脑操作禁用。独立原生探测会报告应用审批不可用，不伪造受信宿主或暗中替换驱动。独立 UIA、截图、输入、Codex 关闭后运行和模型接收截图分别需要证据。

## Alternatives considered

- 复制或修改原生运行时会分发专有实现，并让适配器依赖未公开内部接口。
- 返回原生批准或伪造 Codex 上下文会混淆用户拥有的 DSH 权限与独立提供方限制。
- 超时后自动重试输入，无法区分响应丢失与操作已经执行。
- 模型上报的风险标签不能约束坐标操作的实际含义；完全授权是信任选择，逐次询问保留每次状态改变的人类审查。

## Consequences

无需修改 DSH 核心。即使真实原生输入不可用，本地组合包仍可装配并使用 fake adapter 验证。包路径与版本必须明确配置，运行时变化后重新验收。适配器不是操作系统沙箱：受信插件及不受限文件访问不在其授权保证之内。
